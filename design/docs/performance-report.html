38–74× faster indexed search

For “report” across 100k names, the index takes around 1.3 ms. Against find, the same table gives a 66–113× speedup. Live search beats fd by 2.8× on the flat folder and 3.3× on the tree.

Parallel folders pay off

Live tree search is 2.8× faster than the old single-thread walk. A flat directory is almost unchanged. Tiny folders can be slower than the simple walk because dispatching threads takes time.

Xeon 2.10 GHz, 4 cores, ext4, warm page cache. In-process numbers: median of 100. fd 10.5.0 / find: whole-process median of 7. Process startup adds ~1–4 ms; output printing also differs. Typical repeat variation ±10–20%. The interactive chart uses the separate high-hit query tables, so report timings differ slightly from the table above.

What the excluded run changes

The index skips contents of folders such as node_modules, .git and development caches. Its result set is smaller than the unrestricted disk walk. Even indexing everything, the earlier run beats fd by 2.6–12.2× across these three queries.

The 81.5% raw entry reduction includes EchoFiles’ own synthetic benchmark data. The later notes revise the real-home exclusion estimate to about 72%; it is not evidence that 81% of personal files are junk.

08

What these numbers can tell you.

Measured snapshots from September 2026, not new benchmark runs.

Read the comparison in context

  • All main results use a warm filesystem cache.
  • UI and real-home measurements use the Ryzen laptop; synthetic search uses a four-core Xeon.
  • In-app query times omit command startup and printing.
  • Excluded home indexes cover fewer paths than unrestricted fd.
  • Best-of-7, averages and medians are different summaries.

Still unmeasured or projected

  • Cold-cache and NTFS comparisons.
  • Nautilus frame pacing, valid hover CPU data, and multi-day memory use.
  • Resident-engine queries around 2–3 ms and new windows around 10–20 ms are projections.
  • Pipeline caching saving 10–20 ms is an estimate.
  • NTFS MFT indexing and Windows-drive speed claims await measurements.
