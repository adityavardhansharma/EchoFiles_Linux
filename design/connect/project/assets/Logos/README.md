The EchoFiles logo: three stacked sheets (ember, violet, sky) on a navy tile, the front sheet forming an E-shaped folder. EchoConnect has no mark of its own yet, so its launcher icon uses this one.

- `echofiles-logo.webp` is the original artwork, the source of truth; `echofiles-logo.svg` is the vector redraw (colours baked in from `brand-ember`, `brand-violet`, `brand-sky` on `brand-navy`).
- Use only for the launcher icon, About and onboarding. Never inside the working UI, never recoloured, never on a light ground without its navy tile.
